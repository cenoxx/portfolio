Game Design · Certification project

Put the Fries in the Bag

A game idea and design document created as part of the Epic Games Game Design Certification.

Role

Game designer

Tools

Game design document

Status

Concept and design

The challenge

The project began as a game idea developed for the Epic Games Game Design Certification. The task was to turn that idea into a design document.

The approach

I developed the concept and documented it as part of the certification work, focusing on game design rather than presenting it as a finished game.

The outcome

The project produced a game idea and its design document. It captures the concept at the design stage; no playable build is represented here.
